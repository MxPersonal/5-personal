# فروشگاه نُوین

فروشگاه فارسی محصولات مینیمال و لایف‌استایل با Next.js 16، React 19 و TypeScript. این مخزن به پروژه `template-1` در Vercel متصل است و تغییرات شاخه‌ها به‌صورت Preview منتشر می‌شوند.

## وضعیت فعلی

- صفحه اصلی و کاتالوگ حرفه‌ای و واکنش‌گرا
- صفحات مستقل و SEO-friendly برای هر محصول
- جست‌وجو و فیلتر دسته‌بندی
- سبد خرید پایدار با مدیریت تعداد و Local Storage
- جریان Checkout آماده اتصال به دیتابیس و پرداخت
- صفحات ارسال، بازگشت، پشتیبانی و 404 اختصاصی
- Sitemap، Robots، Manifest، Open Graph و Product Schema
- دسترس‌پذیری صفحه‌کلید، Reduced Motion و اندازه مناسب کنترل‌ها
- هدرهای امنیتی پایه برای Vercel

## مسیر توسعه

مرحله بعد شامل اتصال Supabase، مدیریت موجودی و سفارش، حساب کاربری، پنل مدیریت و پرداخت واقعی است.

## اجرای محلی

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## تست نسخه نهایی

```bash
npm run lint
npm run build
```
