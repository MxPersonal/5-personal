# تمپلیت فروشگاهی نُوین با Next.js

یک تمپلیت ساده و واکنش‌گرای فروشگاهی فارسی (RTL) با Next.js، React و TypeScript.

## امکانات

- صفحه اصلی حرفه‌ای و کاملاً واکنش‌گرا
- فهرست و فیلتر محصولات نمونه
- جست‌وجوی لحظه‌ای محصولات
- سبد خرید تعاملی در سمت کاربر
- متادیتای پایه برای SEO
- بدون نیاز به دیتابیس یا سرویس خارجی برای اجرای نسخه نمایشی

## اجرای محلی

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## تست نسخه نهایی

```bash
npm run lint
npm run build
```

## اتصال به WooCommerce

این پروژه در وضعیت فعلی یک تمپلیت مستقل Next.js است. برای تبدیل آن به فرانت‌اند Headless WooCommerce باید محصولات نمونه فایل `components/storefront.tsx` با داده‌های WooCommerce REST API یا Store API جایگزین شوند و متغیرهای محیطی مربوط به آدرس فروشگاه و کلیدها اضافه شوند. کلیدهای محرمانه را هرگز داخل کد یا GitHub قرار ندهید.
